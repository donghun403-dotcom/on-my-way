# 여기어때 잘난체

`yeogieottae-jalnan2.woff2`는 여기어때컴퍼니 공식 잘난체 페이지가 사용하는
`Jalnan 2 Regular` 웹폰트 원본입니다. 파일을 변환하거나 수정하지 않았습니다.

- 공식 소개 및 다운로드: https://gccompany.co.kr/font
- 공식 라이선스 가이드: https://image.goodchoice.kr/images/jalnan_font/jalnan-font-202004ver.pdf
- 공식 웹폰트 원본: https://framerusercontent.com/assets/tei8CJnHqrxTy9hMp7WwAK6aIA.woff2
- SHA-256: `e8dd022ed1c566d75b0ddf64e32bb36e93d9744b49a296c0f75242553bd3bfae`
- 원본 metadata family: `Jalnan 2 Regular` / `여기어때 잘난체 2`

여기어때컴퍼니의 라이선스 가이드는 개인과 기업을 포함한 모든 사용자에게
무료 사용을 허용하고, 상업적 사용과 라이선스 안내를 포함한 소프트웨어
임베딩·번들을 허용합니다. 글꼴 파일 자체의 유료 판매와 임의 수정·개작은
금지됩니다.

출처 표기:

> 이 페이지에는 (주)여기어때컴퍼니가 제공한 여기어때 잘난체가 적용되어 있습니다.
