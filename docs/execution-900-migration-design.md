# 실행 화면 900 이관 설계

`styles.css`에 `font-weight: 900`이 203개 남아 있다. 이전 폴백 글꼴(맑은 고딕, Apple SD
Gothic Neo)에서는 700·800·900이 전부 같은 합성 볼드로 렌더링돼 구분이 없었고, 그래서
900은 의도적으로 고른 값이 아니다. Pretendard Variable 아래에서는 900이 진짜 Black으로
렌더링되므로 화면에 나타날 때마다 재판단이 필요하다 — `docs/design-tokens.md`가 이 일을
"A·B 단계가 이어받는다"로 남겼고, 이 설계가 그 첫 조각이다.

## 범위 — `.execution-page` 계열 66곳

| 묶음 | 수 |
| --- | --- |
| 공통·딥 스테이트 (달력·데이 페이지·다이어리 북·수정 제안·포커스 모드 등) | 46 |
| 기억 탭·올리 (`.memory-*`, `.save-memory-button` 등) | 12 |
| 계획 탭 시트 (`.plan-adjust-*`, `.plan-undo-banner` 등) | 4 |
| 메이트 탭 (`#view-mate` 2) + 시트 헤더 (`#myPageSheet` · `#personalitySheet`) | 4 |

**이번에 하지 않는 것**: `.home-page` 27, 결제·가격 9, 샘플 북 4, 관리자 7, 롱테일 약 80,
그리고 `core-loop-v2.css`의 2곳(프로토타입은 자체 토큰 체계를 갖는다). 근거는 검증
가능성이다 — 66곳은 Task 5가 오늘·계획 탭에 깔아둔 실측 경로의 연장선에 있고, 나머지는
도달 경로부터 새로 설계해야 한다. 한 번에 옮기는 것은 계획이 이미 기각한 접근이다.

## 방법 — 마크업 대조 분류 + 도달 가능 화면 스폿 실측

1931905가 32곳을 이 방법으로 재판단해 성공한 전례를 따른다. 이 코드베이스는
`<span>킥커 캡션</span><h2>진짜 제목</h2>` 짝을 반복하므로, 셀렉터만 보지 않고 실제 HTML
마크업과 대조해 3갈래로 분류한다.

| 성격 | 배정 |
| --- | --- |
| 킥커·라벨·legend·칩·배지·작은 버튼 (짧은 UI 문구) | `--weight-emphasis` (600) |
| 섹션·카드 제목 | `--weight-title` (700) |
| 화면 제목(H1급)·큰 숫자·주요 CTA | `--weight-display` (800) |

- **분류 결과표가 산출물이다.** 66행 각각에 셀렉터·마크업 근거·배정을
  `docs/artifacts/execution-900-classification.md`로 남긴다. Task 5의 실수 — 브리프가
  두 갈래만 적어 크롬 30곳이 제목 굵기로 몰린 것 — 를 표가 막는다.
- e2e로 도달 가능한 화면(오늘·계획·메이트·기억 탭, 달력, 마이페이지 시트)은 이관 전후를
  실측해 대조한다.
- 딥 스테이트(다이어리 북 생성·수정 제안·지우기 플로)는 마크업 분류 + 기존 e2e에 맡긴다.
  시드 데이터까지 만들어 전수 실측하는 것은 비용 대비 이득이 없어 기각했다.

## 원칙 — 표에 맞지 않는 것을 억지로 맞추지 않는다

- **글리프 의사요소** (`.execution-check::after`의 체크마크 등): 텍스트 위계가 아니라
  아이콘이다. 역할 토큰을 배정하지 않고 리터럴 + 사유 주석으로 남긴다.
- **본문 성격의 강조** (올리 말풍선·토스트류)를 새로 만나면: 700 + 판단 보류 주석.
  이전 브랜치가 `.ollie-message p`·`.app-toast`에 쓴 정책과 같다. 굵기 역할 표를
  늘릴지는 별도 결정으로 미룬다 — 이 작업이 임의로 채우지 않는다.

## 재발 방지 — 잔여 수 래칫

`styles.css`의 `font-weight: 900` 잔여 수를 고정하는 테스트를 추가한다. 새 900이
들어오면 실패하고, 후속 이관이 끝날 때마다 수를 내린다. 값 자체는 6단계 계약 안이라
기존 계약 테스트(fonts.test.mjs)가 못 잡는 유입을 이 래칫이 잡는다.

**실행 결과 정정(2026-07-31)**: 최종 래칫은 137이 아니라 **139**다. 분류에서 글리프
캐리어 2곳(`.execution-check::after`, `.calendar-day-detail-list i` — 둘 다 "✓")이
유지(리터럴) 판정을 받았고, 위 글리프 원칙의 귀결로 900 리터럴 + 주석으로 남는다.
139 = 다음 단계 몫 137 + 글리프 2.
