# Pricing System v2 — 수동 온보딩 + 올리 치어링 전환

> v1과의 핵심 차이: 온보딩의 AI 목표 계획 생성이 제거되고, 계획은 유저가 직접 만든다.
> AI(올리 에너지)는 실행 단계의 소통(대화·계획 다듬기·주간 최적화)에만 쓰인다.
> 관련 코드 계약: `/api/ai/goal-plan` 라우트 제거, `goalPlanGeneratedAt` 필드 제거,
> `GOAL_PLAN_LIMIT_REACHED` 오류 코드 폐기, 체험 시작은 가입 시각 기준 서버 권위.

## Plans

### FREE (1-day trial)

- 체험은 회원가입과 동시에 시작 (서버 권위: `trialStartedAt` / `trialExpiresAt`)
- 내 계획 직접 만들기 (수동 온보딩) · 수동 수정 무제한 · AI 비용 0원
- 올리 에너지 10 (≈ 올리와 대화 10회)
- 올리의 매일 축하·위로 메시지 (에너지 미차감, 하루 각 1회 상한)
- 매일 스케줄 체크, 집중 타이머, 감정 다이어리
- 결제정보 불필요 · 자동 결제 없음 · 종료 후 결제 전까지 이용 일시 중단

### PRO — 월 2,900원

- 목표와 일정 무제한
- 매월 올리 에너지 300 (이월 없음)
- 올리의 매일 축하·위로 메시지를 구독 기간 내내 (에너지 미차감, 하루 각 1회 상한)
- 주간 회고와 올리 성장, 전체 기록, 프리미엄 위젯

> 축하·위로는 로그인한 회원이면 체험 중에도 받는다. 첫날에 "올리가 먼저 말을 건다"를
> 경험하지 못하면 체험이 그냥 빈 계획표로 끝나기 때문이다. 비용은 하루 각 1회 상한이
> 막고, 게스트와 상한 도달·실패는 서버를 부르지 않고 로컬 문구로 대체한다.

## Ollie Energy costs (v2)

| 기능 | 에너지 | AI 출력 토큰 상한 |
| --- | ---: | ---: |
| 올리와 대화 (유저가 먼저 말 걸기) | 1 | 700 |
| 계획 다듬기 (내 계획 → AI 변경안) | 3 | 2,800 |
| 주간 최적화 | 5 | 2,800 |
| 매일 축하·위로 (자동, 하루 각 1회) | 0 | 700 |

제거된 항목: "AI 목표 계획 생성" (온보딩 수동화), "목표 전체 재설계 10" (goal-plan 의존 기능),
"오늘의 한 걸음 생성" (라우트 없음), "목표 이해 정리" (게스트 온보딩과 함께 제거).
구현된 `AI_CREDIT_COSTS`는 `companion_chat 1 / revise_plan 2 / recovery_plan 3 / reschedule_plan 4`이고,
이 표의 3·5는 아직 반영되지 않은 제안값이다 (아래 "미정" 참고).
에너지는 매월 리셋되고 이월되지 않는다. 잔량 20% 이하에서 경고를 표시한다.

## Unit economics guardrails (v2)

- PRO 매출: 월 2,900원. 총마진 60% 목표 → 변동비 상한 월 1,160원, AI 비용 목표 월 1,000원 이하 (v1과 동일).
- v1 대비 개선: 신규 유저당 온보딩 AI 비용이 0원이 됐다 (기존: 가입 전 비로그인 시도 포함 3,000토큰 호출 + 오류 재시도 비용).
- 최악 소비 패턴이 "계획 생성 반복"(3,000토큰)에서 "대화 반복"(700토큰)으로 바뀌어 에너지 1당 최대 토큰 비용이 크게 낮아졌다.
- 300 에너지 전량 소진 시에도 에너지당 혼합 AI 비용이 3.33원 이하면 예산 내 (v1 기준 유지).
- 무료 축하·위로 메시지는 에너지 미차감이므로 서버에서 하루 각 1회로 상한을 강제한다. **구현 완료**: `checkDailyCheerAllowance`(worker.mjs)가 KST 일자 버킷으로 판정하고, AI가 성공한 뒤에만 소진 처리한다(실패는 재시도 가능). 상한 초과 요청은 AI를 부르기 전에 429로 끊어 비용을 만들지 않는다.
- 축하·위로가 체험 회원에게도 열려 있으므로 예산 라인은 "PRO 유저당 월 최대 60회"가 아니라 "로그인 회원당 월 최대 60회 × 700토큰"으로 잡는다. 체험은 24시간이라 유저당 최대 2회로 상한이 자연히 낮다.
- 결제 수수료, 카카오 알림톡, 재시도, CS 변동비는 별도 추적 (v1과 동일).

## 미정 (구현과 문서가 아직 다른 값)

이 문서의 제안값과 배포된 `plan-policy.mjs`가 다음 항목에서 다르다. 가격 결정이 필요하며,
결정 전까지는 코드 값이 사실이다.

| 항목 | 이 문서 | 구현 |
| --- | ---: | ---: |
| PRO 월 가격 | 2,900원 | 4,900원 (`PLAN_CONFIG.pro.priceKRW`) |
| PRO 월 에너지 | 300 | 250 (`monthlyCredits`) |
| 계획 다듬기 | 3 | 2 (`revise_plan`) |
| 주간 최적화(전체 일정 재조정) | 5 | 4 (`reschedule_plan`) |
| 회복 계획 생성 | 표에 없음 | 3 (`recovery_plan`) |
| FREE 체험 에너지 | 표에 없음 | 15 (`PLAN_CONFIG.pro.trial.credits`) |

## Metrics to monitor (v2)

- 퍼널: step1~4_enter(목표→리듬→할 일→마무리) → plan_complete → signup_gate → signup_start → signup_success → trial_start
- 계획 완성률 (step1_enter 대비 plan_complete)
- 가입 게이트 전환율 (signup_gate 대비 signup_success)
- 체험 → PRO 전환율
- 에너지 소비 분포 (대화 vs 계획 다듬기 vs 주간 최적화), 유저당 평균·95퍼센타일
- 무료 축하·위로 발송량과 토큰 비용 (로그인 회원당 · 체험/PRO 분리)
- 에너지당 혼합 AI 비용, 20% 경고 도달 비율, 추가 에너지 팩 전환율
