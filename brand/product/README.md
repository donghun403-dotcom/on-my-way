## 마케팅에서 알아야 할 제품 사실 요약

Phase 4(앱 공개) 준비를 시작할 때 쓴다. 상세는 `../marketing/plugin/src/skills/on-my-way-brand/references/product-facts.md`.

- **한 줄**: MBTI와 사주 기반 성향 분석으로 나에게 맞는 목표 실행 계획을 만들고, 매일 체크인하면 올리와 성장 대상이 자란다
- **요금제**: FREE(1일 체험 · AI 계획 1개 · 올리 에너지 10 · 결제수단 불필요) / PRO 월 2,900원(무제한 · 에너지 300 · 주간 회고 · 전체 기록)
- **탭 구조**: 오늘 / 계획 / 올리 / 기록
- **성장 테마**: 식물 · 강아지 · 고양이 · 집짓기

## 현재 출시 상태 (2026-07 기준 — 바뀌면 갱신할 것)

- 결제 **비활성** (`PAYMENTS_ENABLED=false`)
- 소셜 로그인: 카카오·네이버·구글 구현 / **애플 미구현**
- 실기기 모바일 QA, 스토어 등록 자료 **없음**
- 미구현 기능: 캘린더 연동, 친구·스터디 공유, 챌린지, 전문가 코칭, 팀 목표 관리

**마케팅 콘텐츠에서 위 미구현 항목을 현재형으로 말하지 않는다.**
