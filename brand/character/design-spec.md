## 1. 형태 — 확정된 사실

바이블 §12에서 미확정이던 항목 중 **4개가 에셋으로 확정**되었다.

| 항목 | 확정 내용 |
| --- | --- |
| **팔** | **있다.** 짧고 뭉툭한 벙어리장갑형(mitten). 손가락 없음. 구름과 같은 재질·색. 어깨 아래쪽 좌우에서 나온다 |
| **다리** | **있다.** 팔보다 길고 가는 원통형. 발 구분 없이 끝이 둥글게 마감. 2개 |
| **나무 위치** | **올리 기준 오른쪽 어깨 위** (보는 사람 기준 우상단). 머리 위 중앙이 아니다 |
| **나무 형태** | **테라코타 화분에 심긴 어린 새싹.** 잎 4~5장, 가는 줄기 2~3갈래. 화분이 구름 표면에 반쯤 파묻힌 듯 얹혀 있다 |

### 비율 (celebrate 기준, 전체 높이 = 100)

| 요소 | 값 |
| --- | --- |
| 구름 몸통 높이 | 약 46 |
| 구름 몸통 너비 | 약 88 (전체 폭 대비) |
| 화분 + 잎 높이 | 약 33 (구름 몸통의 70%) |
| 다리 길이 | 약 21 |
| 팔 길이 | 약 12 |
| 눈 지름 | 구름 몸통 너비의 약 6% |

**나무는 작지 않다.** 구름 몸통 높이의 약 70%로, 실루엣에서 확실히 읽힌다. 바이블 §6의 "나무는 올리보다 커 보이지 않게"는 지켜지되, 눈에 안 띌 정도로 줄이면 안 된다.

### 구름 실루엣

크기가 다른 둥근 덩어리 **4~5개**가 붙은 형태. 상단에 큰 봉우리 1개 + 좌우 중간 봉우리, 하단은 완만하게 이어진다. 완벽한 원형이 아니고, 좌우 비대칭이다.

### 브랜드 컬러와의 관계 — 중요

앱 브랜드 컬러(`#1F41B0` `#F4F4F4` `#E34054`)와 **올리 팔레트는 다르다.**

- 눈·입의 `#172F58`은 브랜드 블루 `#1F41B0`보다 훨씬 어둡고 채도가 낮다
- 올리 어디에도 `#E34054`(포인트 레드)가 쓰이지 않았다. 볼터치는 훨씬 연한 `#F8C0B9`
- 배경 그레이 `#F4F4F4`는 구름 본체 `#F4F6F8`과 거의 같아 **배경에 올리를 얹으면 묻힌다**

**결론**: 올리 콘텐츠에는 올리 팔레트를 쓴다. 브랜드 컬러를 강제하지 않는다. 배경이 필요하면 `#F4F4F4`보다 한 단계 진한 톤이나 옅은 하늘색을 쓴다.

## 3. 렌더 스타일

- **3D 소프트 렌더.** 2D 플랫 일러스트가 아니다
- 재질은 **매트한 실리콘/점토 느낌.** 광택(specular)이 거의 없고 표면이 부드럽다
- 광원은 **좌상단 단일 광원.** 그림자는 우하단에 부드럽게
- 외곽선(스트로크) 없음. 형태는 명암으로만 구분
- 배경 투명 PNG

### 애니메이션에 미치는 영향

3D 렌더라 **프레임 단위 손그림 애니메이션은 사실상 불가능**하다. 대신 이 스타일은 다음이 쉽다.

| 가능 | 방법 |
| --- | --- |
| 부풀기·줄어들기 | 스케일 트윈 |
| 둥실거리기 | Y축 위치 + 살짝 회전 |
| 잎 흔들림 | 잎 레이어 분리 후 회전 |
| 감정 색 변화 | 구름 위에 컬러 오버레이 레이어 (곱하기 또는 소프트라이트) |
| 표정 변화 | **눈·입만 별도 레이어로 교체** ← 가장 중요 |
| 비·번개·무지개 | 파티클/오버레이 |

**권장**: 올리 몸통을 배경 레이어로 두고 **눈·입·볼터치·팔·다리·나무를 분리한 PSD 또는 레이어드 파일**을 하나 만들어두면, 이후 모든 콘텐츠 제작 속도가 몇 배 빨라진다. 이게 지금 가장 우선순위 높은 제작 투자다.

## 5. 바이블과 현재 에셋의 차이 — 결정 필요

| # | 바이블 | 현재 에셋 | 판단 |
| --- | --- | --- | --- |
| 1 | "작은 **올리브나무**" | 종을 알 수 없는 **어린 새싹**. 올리브 특유의 은녹색 좁은 잎이 아니고, 열매도 없음 | 잎을 올리브형으로 바꿀지, 새싹 그대로 두고 설정을 조정할지 |
| 2 | 잎은 "올리브 그린" | 실제로는 **연한 민트/청록** | 색을 바꿀지, 설정을 실제 색에 맞출지 |
| 3 | 감정을 잘 지나온 날 "**올리브 열매**가 맺힌다" | 열매 에셋 없음 | 열매 디자인 필요. 새싹 상태에서 열매가 맺히면 어색하므로 성장 단계 설계가 선행되어야 함 |
| 4 | "구름과 나무가 **함께 떠다닌다**" | 화분째 어깨에 얹혀 있음 | **에셋이 더 낫다.** "데리고 다닌다"가 시각적으로 명확. 바이블을 에셋에 맞추는 것을 권장 |
| 5 | 나무는 "작고 단순한 실루엣" | 구름 높이의 70%로 꽤 큼 | 현행 유지 권장. 작아지면 두 번째 표정 역할을 못 한다 |

### ✅ 결정됨 (2026-07-26) — 올리브로 확정, B안 채택

나무는 **올리브**로 확정되었다. 전환 방식은 **B안(올리브 힌트)** — 잎 비율 2.3:1, 세이지 그린 `#9ABE9E`(뒷면 `#C6D6C0`), 마주나기 6장, 올리브 열매 `#5C6E4A`. **렌더 스타일·구름·얼굴·팔다리·화분은 변경 없음.**

기존 에셋 5종과 기제작 릴스 2편은 **재작업하지 않는다.** '어린 올리브' 단계로 재정의해 성장 서사에 흡수한다. "올리브"라는 명칭은 첫 열매가 맺히는 편(캘린더 08.19)에서 처음 공개한다.

상세 근거·성장 단계·체크리스트는 **`olive-decision.md`** 참조.

<details><summary>결정 당시 검토했던 두 선택지</summary>


- **A안 — 에셋에 설정을 맞춘다**: 나무를 "이름 없는 어린 나무"로 두고, 열매는 올리브가 아닌 다른 것으로. 새로 그릴 게 적다
- **B안 — 설정에 에셋을 맞춘다**: 잎을 올리브형(좁고 은녹색)으로 다시 그린다. "올리 = 올리브"라는 이름 연결이 살아난다

이름이 OLLIE로 확정된 이상 브랜드 논리는 올리브 쪽이 강하다.
