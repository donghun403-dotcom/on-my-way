# 올리 · On My Way 자동 마케팅 팀

인스타그램·페이스북 콘텐츠를 기획부터 카피까지 자동으로 만들어내는 Cowork 플러그인.

## 지금 이 플러그인이 하는 일

**앱 홍보가 아니라 올리를 독립 캐릭터로 세우는 것.**

> 올리는 마음의 날씨가 온몸에 드러나고, 그 날씨를 먹고 자라는 작은 올리브나무와 함께 떠다니는 구름 친구. 구름은 순간 감정, 올리브나무는 누적된 마음이다. 대표 미스터리는 **"올리는 왜 작은 나무를 데리고 어딘가로 가고 있는가?"**

| 단계 | 목표 | 앱 노출 |
| --- | --- | --- |
| **Phase 1 — 각인** ← **지금** | 올리의 외형·감정 표현 각인, 팬 확보 | **없음** |
| Phase 2 — 미스터리 | "어디로 가나" 궁금증 증폭 | 없음 |
| Phase 3 — 역할 발견 | 올리가 하는 일이 드러남 | 암시만 |
| Phase 4 — 공개 | On My Way 연결 | 전면 |

Phase 1 판단 기준 한 줄: **이 콘텐츠가 앱 없이도 그 자체로 재미있는가?**

## 팀 구성

각 스킬이 마케팅 팀의 한 사람에 해당한다.

| 역할 | 스킬 | 하는 일 |
| --- | --- | --- |
| 브랜드 매니저 | `on-my-way-brand` | 현재 Phase, 올리 캐릭터 바이블, 콘텐츠 4축을 모든 산출물에 강제. 다른 스킬이 자동 참조 |
| 콘텐츠 디렉터 | `weekly-content-drop` | **메인 실행기.** 한 주치(릴스 2 + 캐러셀 1 + 스토리 7일)를 한 번에 완성 |
| 기획자 | `content-calendar` | 주 3회 4축 로테이션 캘린더, 감정 중복 방지 |
| 영상 연출 | `reels-script` | 올리 에피소드 릴스 — 5단 구조, 컷 지시, 저비용 대안 |
| 만화·카드 작가 | `carousel-post` | 4컷 만화와 감정 도감 캐러셀 |
| 데이터 분석가 | `sns-performance-review` | 인사이트 진단 + Phase 1 정성 평가 → 다음 주 조치 3개 |
| 검수 | `marketing-compliance-check` | 정신건강·캐릭터 묘사 검수 (Phase 4부터는 광고법 6축 추가) |

## 쓰는 법

가장 자주 쓸 명령:

```
이번 주 콘텐츠 만들어줘
```

→ `weekly-content-drop`이 돌면서 월·수·금 게시물, 스토리 7일 계획, 에셋 체크리스트, 검수까지 끝낸 마크다운 패킷 하나를 준다.

그 외:

| 하고 싶은 것 | 이렇게 말하면 된다 |
| --- | --- |
| 한 달치 계획 | "9월 콘텐츠 캘린더 만들어줘" |
| 릴스 하나 | "올리가 부끄러워하는 에피소드 릴스로" |
| 4컷 만화 | "올리랑 나무가 반대로 반응하는 4컷 만화" |
| 검수 | "이 에피소드 캐릭터 일관성 봐줘" |
| 성과 분석 | "이번 주 인사이트 분석해줘" (수치 + 댓글 내용 붙여넣기) |

## 운영 전제

- **주 3회**: 월(릴스·감정 날씨) / 수(캐러셀·올리↔나무) / 금(릴스·여정의 단서 또는 감정) 20시 KST
- **스토리 매일** — 시그니처는 "오늘 당신의 구름은 무슨 날씨예요?"
- **단일 이미지는 만들지 않는다** — 2026년 기준 인게이지먼트 -46%
- **페이스북은 크로스포스팅만** — 국내 페북 릴스 이용률 6.2%
- **Phase 1 콘텐츠 4축**: C1 감정 날씨 / C2 올리↔나무 / C3 여정의 단서 / C4 참여
- **한 편에 감정 하나, 시각적 반전 하나.** 4주 안에 같은 감정을 두 번 쓰지 않는다

## 제작 현실

풀 애니메이션은 주 3회로 지속할 수 없다. 모든 대본에 **저비용 대안 연출**이 함께 나온다.

| 난이도 | 형태 |
| --- | --- |
| 하 | 스틸 3~5장 + 크로스페이드 + 자막 |
| 중 | 스틸 + 부분 모션 (구름 부풀기, 잎 흔들림, 비 파티클) |
| 상 | 프레임 애니메이션 — 월 1회 이하 |

구름의 형태 변화와 나무의 잎 흔들림만 움직여도 감정 표현은 성립한다.

## 주간 자동 실행

매주 자동으로 다음 주 콘텐츠를 받으려면 Claude에게 이렇게 말한다:

> 매주 수요일 오전 9시에 다음 주 올리 콘텐츠를 만들어주는 작업 등록해줘

## 이 플러그인이 하지 않는 것

- **자동 게시하지 않는다.** 최종 게시는 사람이 한다.
- **그림을 그리지 않는다.** 콘티, 컷 지시, 대사, 캡션까지가 범위다.
- **Phase 1에서 앱을 언급하지 않는다.** 예외 없다.
- **검증 안 된 수치를 쓰지 않는다.**

## 아직 확정이 필요한 항목

`skills/on-my-way-brand/references/ollie-voice.md` §12 참조. 영문 표기는 **OLLIE로 확정**되었고, 나머지 6개(나무 위치·비율, 팔다리 유무, 색상값, 성별, 목소리, 최종 목적지 설정)는 미확정이다. 미확정 항목에 걸리는 연출은 피해서 콘티를 짠다.

## 데이터 기준

플랫폼 사양·벤치마크는 2026년 7월 기준이다 (Metricool 2026, Socialinsider 2026, KT 나스미디어 2026 NPR, 오픈서베이). 출처는 `skills/on-my-way-brand/references/platform-rules.md` 하단에 있다.

## 법적 고지

`marketing-compliance-check`는 법률 자문이 아니다. 인플루언서 협업, 결제 활성화, 유료 광고 집행 전에는 광고법 전문가 검토를 권한다.
