# 시즌 훅 캘린더 (한국)

> ⚠️ **Phase 1~3에서는 이 문서를 거의 쓰지 않는다.** 수능·공채·자격증 같은 시즌은 앱 소재이지 올리 소재가 아니다. Phase 4(On My Way 공개) 이후에 쓴다.
>
> **Phase 1에서 쓸 수 있는 것은 계절 자체뿐이다** — 첫눈, 장마, 벚꽃, 태풍, 안개, 폭염, 낙엽. 올리는 날씨 캐릭터이므로 계절 현상과 궁합이 좋다. 예: 장마철 = "비가 계속 오는데 나무만 신났다", 첫눈 = "구름인데 눈은 처음 만들어본다".

목표 설정 수요가 몰리는 시점. 캘린더를 짤 때 해당 기간의 항목을 최소 1~2개 반영한다.

## 월별

| 월 | 시즌 이슈 | 목표 유형 | 콘텐츠 각도 |
| --- | --- | --- | --- |
| **1월** | 새해 목표, 신년 계획 | 전체 | 최대 성수기. "1월 3주차에 무너지는 이유" — 실패를 전제로 한 설계 |
| **2월** | 새 학기 준비, 설 연휴 후 리셋 | 학습, 습관 | "2월에 다시 시작하는 사람들" |
| **3월** | 개강, 신입 입사, 상반기 자격증 | 학습, 커리어 | 3개월 단위 계획 소재 |
| **4월** | 중간고사, 상반기 공채 | 시험, 취업 | 단기 집중 계획 |
| **5월** | 여름 대비 시작 | 운동, 다이어트 | "여름까지 D-60" 역산 |
| **6월** | 상반기 마감, 기말 | 회고 | "반년 지났는데 목표 어디까지?" — 회고 기능 소구 |
| **7월** | 하반기 시작, 휴가 | 리셋 | "하반기는 다르게" |
| **8월** | 하반기 공채, 휴가 후 복귀 | 취업 | 복귀 루틴 재설계 |
| **9월** | 추석, 하반기 자격증, 수능 D-60 | 시험 | 막판 스퍼트 계획 |
| **10월** | 수능 D-30, 연말 목표 점검 | 시험 | 초단기 계획 |
| **11월** | 수능, 연말 마감 | 회고, 전환 | "수능 끝나고 뭐 할까" — 새 목표 유입 |
| **12월** | 연말 회고, 내년 계획 | 회고, 신년 | 1월 성수기 사전 빌드업. **12월 중순부터 신년 콘텐츠 시작** |

## 반복 주기 훅

| 주기 | 훅 |
| --- | --- |
| 매주 월요일 | 주간 계획 세우기 |
| 매주 일요일 | 주간 회고 (PRO 기능 연결) |
| 매월 1일 | 월간 목표 리셋, 올리 에너지 초기화 |
| 매월 말 | 이번 달 성장 결과 공유 (UGC 유도) |

## 시험·채용 일정 (매년 확인 필요)

날짜는 해마다 바뀐다. **캘린더를 만들 때 해당 연도 일정을 웹으로 확인**한 뒤 반영한다.

- 토익 / 토스·오픽: 월 1~2회
- 컴활·정보처리기사 등 국가기술자격: 연 3~4회 (1·2·3회차)
- 대기업 상반기 공채: 3~4월 / 하반기: 8~9월
- 수능: 11월 중순
- 공무원 시험: 국가직 4월, 지방직 6월 전후

## 시즌 콘텐츠 주의

- 시즌 훅은 **P2·P3 축과 결합**할 때 가장 강하다. "수능 D-60 계획표" = P3, "수험생 MBTI별 슬럼프 오는 시기" = P2.
- 시즌은 훅일 뿐 소구점은 제품이다. 시즌 인사말만 올리지 않는다.
- 수능·공채처럼 **절박한 시즌**일수록 합격 보장·운세 단정 표현이 위험하다. `marketing-compliance-check` 필수.
