# On My Way 제품 팩트시트

> ⚠️ **Phase 1~3에서는 이 문서를 콘텐츠에 사용하지 않는다.** 현재 목표는 앱 홍보가 아니라 올리를 독립 캐릭터로 각인시키는 것이다. 이 파일은 Phase 4(On My Way 공개) 이후, 또는 사용자가 명시적으로 앱 마케팅을 요청할 때만 연다.
>
> 단 하나 지금부터 알고 있어야 할 것: **올리가 찾고 있던 사람은 완벽한 사람이 아니라 다시 한 걸음을 시작하려는 사람이었다.** 이 연결 방향에 어긋나는 캐릭터 설정을 쌓지 않는다.

콘텐츠에 쓸 수 있는 **검증된 사실만** 담는다. 여기 없는 수치는 창작 금지.

## 포지셔닝

성향 기반 목표 설정 + 실행 체크를 결합한 목표 달성 파트너.

핵심 약속:
> "당신의 성향을 이해한 뒤, 목표를 세우는 방식부터 실행하고 점검하는 방식까지 맞춰서 함께 간다."

## 사용자가 겪는 문제 (콘텐츠 훅의 원천)

콘텐츠 아이디어가 막히면 이 목록에서 하나를 고른다. 전부 실제 유저 문제 정의에서 나온 것이다.

1. 목표가 추상적이다
2. 기간과 실행량이 현실적이지 않다
3. 오늘 무엇을 해야 하는지 명확하지 않다
4. 본인 성향과 맞지 않는 계획 방식을 반복한다
5. 계획 방식이 너무 일반적이라 나에게 안 맞는다
6. 계획이 틀어졌을 때 다시 조정하지 못한다
7. 혼자 하니 체크와 피드백이 끊긴다
8. 성취감이 늦게 와서 중간에 포기한다

가장 강한 한 줄: **"목표를 세운 날은 분명했는데, 일주일 뒤엔 흐려진다."**

## 작동 방식 4단계

1. **성향 파악** — MBTI, 만세력 정보, 목표 유형, 현재 상태 입력
2. **목표 설정 방식 제안** — 몰입형 / 루틴형 / 보상형 / 점검형 중 맞는 방식 제안
3. **실행 계획 생성** — 월간 → 주간 → 일간으로 쪼개고 오늘 할 일 제시
4. **체크인과 조정** — 완료 여부·어려움·누락 일정을 반영해 계획 재조정

## 성장 시스템 (P1 올리 축의 핵심 소재)

- 목표 시작 시 성장 테마를 고른다: 식물 / 강아지 / 고양이 / 집짓기
- 성장 대상의 **이름**과 목표 달성 시 **완성 모습**을 유저가 직접 설정한다
- 목표 기간을 하루 단위 성장 단계로 분할한다 (30일 목표 → 30단계)
- 하루 계획을 완수하면 그날의 성장 단계가 열린다
- 부분 완료 시에도 작은 변화 + 응원 메시지를 준다
- **실패한 날에도 성장이 망가지지 않는다.** 다음 날 다시 이어간다
- 목표 종료 시 완성된 성장 결과물을 저장·공유할 수 있다

> 마케팅 관점: 이 "실패해도 안 무너진다"가 경쟁 습관앱과의 가장 큰 정서적 차별점이다. 스트릭(연속 기록) 앱이 주는 압박의 반대편에 선다.

## 전환 퍼널

방문 → 성향 기반 목표 설계 CTA → 목표 유형·기간·현재 상태 입력 → MBTI·생년월일 등 선택 입력 → 성향에 맞는 계획 미리보기 → 하루 체험 시작 또는 결제 → 회원가입 → 전체 기간 계획 생성 → 체크인 반복 → 유료 유지

**무료 미리보기 범위**: 성향 요약, 추천 목표 설정 방식, 이번 주 실행 계획 일부, 오늘의 첫 행동, 체크·조정 맛보기

**결제 후 범위**: 전체 기간 계획, 앱 내 목표 저장, 데일리 체크인, 목표 달성 게이지, 일일 성장 단계, 성장 대상 응원 메시지, 전체 스케줄 PDF, 주간 회고 리포트, 놓친 계획 재조정

> 마케팅 관점: **"결제수단 없이 체험 가능"**은 전환 카피에서 가장 강한 무기다. 반드시 명시한다.

## 현재 운영 상태 (2026년 7월 기준 — 콘텐츠 기획 시 유의)

- 결제는 아직 비활성(`PAYMENTS_ENABLED=false`) 상태다. 유료 결제를 전제로 한 CTA를 쓰기 전에 사용자에게 결제 활성화 여부를 확인한다.
- 소셜 로그인은 카카오·네이버·구글이 구현되어 있고 애플 로그인은 미구현이다. "애플로 3초 만에 시작" 같은 카피를 쓰지 않는다.
- 실기기 모바일 QA와 스토어 등록 자료가 아직 없다. 앱스토어/플레이스토어 링크를 전제로 한 CTA를 쓰기 전에 확인한다.

이 섹션의 상태는 바뀔 수 있다. 전환 CTA를 쓰기 전에 **한 번은 사용자에게 현재 가입 가능 경로를 확인**한다.
