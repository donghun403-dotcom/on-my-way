# 캐러셀

먼저 `on-my-way-brand` 스킬의 **현재 Phase**와 `references/ollie-voice.md`를 확인한다.

## 캐러셀의 역할

캐러셀은 **저장(Saves)을 만드는 포맷**이다. 단일 이미지 대비 저장 9배, 인스타 포맷 중 인게이지먼트율 1위(0.55%).

Phase 1에서는 여기에 하나가 더해진다 — **애니메이션 없이 만들 수 있는 이야기 포맷.** 주 3회 페이스를 지탱하는 현실적 기둥이다.

## Phase 1의 두 가지 캐러셀 유형

### A. 4컷 만화 (주력, C2 축)

올리와 나무의 엇갈린 반응을 4~6컷으로. 스틸 일러스트만으로 완성된다.

| 컷 | 역할 |
| --- | --- |
| 1 | 사건 — 훅. 여기서 스와이프가 결정된다 |
| 2 | 구름의 날씨가 변한다 |
| 3 | **나무가 예상 밖으로 반응한다** ← 핵심 |
| 4 | 반전 또는 여운 |
| (5~6) | 잔여 반응 — 잎 한 장, 물방울, 구름 조각 |

마지막 컷에 **잔여 반응 한 컷**을 붙이면 저장률이 올라간다. 그 한 컷만 캡처해 저장하는 사람이 생긴다.

### B. 감정 도감 (C1 축)

`ollie-voice.md` §5 감정표를 시각화한 레퍼런스 카드. 저장 목적으로는 가장 강한 포맷이다.

- "올리의 15가지 날씨" 중 5~6개를 묶어 한 편으로
- 한 슬라이드 = 감정 하나 = 구름 상태 + 나무 상태 + 한 줄 대사
- 마지막에서 두 번째 슬라이드에 **전체 요약 그리드** — 이것만 저장해도 가치가 완결된다

**주의**: 도감을 "감정 관리법"으로 만들지 않는다. 올리의 세계 설명이지 자기계발 정보가 아니다.

## 사양

| 항목 | 값 |
| --- | --- |
| 비율 | **1080 × 1350px (4:5 세로)** — 1:1 대비 피드 점유 +33% |
| 장수 | **5~8장** (4장 미만은 저장 유인 약함, 10장 초과는 완주율 하락). 최대 20장 |
| 본문 한 줄 | 20자 이내 |
| 슬라이드당 분량 | 본문 최대 3줄 + 보조(라벨·주석) 1줄 |

색은 `ollie-voice.md` §6을 따른다. 구름은 따뜻한 흰색·크림색 기본, 감정색은 안쪽 빛과 가장자리에만. **앱 브랜드 컬러를 강제하지 않는다.**

## 슬라이드 구조

장수와 무관하게 **상대 위치**로 배치한다.

| 위치 | 역할 |
| --- | --- |
| **첫 장** | 훅. 구름+나무 실루엣이 읽혀야 한다 |
| **중간** | 한 슬라이드 = 한 개념 또는 한 컷 |
| **마지막-1** | 요약 또는 잔여 반응. **이것만 저장해도 가치가 완결되는 장** |
| **마지막** | CTA — Phase 1에서는 팔로우·저장·댓글 요청만 |

## 필수 규칙

- **첫 슬라이드는 그림이 먼저다.** 텍스트를 얹더라도 6~14자.
- 2·3번 슬라이드에 **스와이프 유인**을 넣는다. 3번째 이상 스와이프되면 알고리즘이 재배포하는 경향이 있어 24~48시간 후 2차 노출이 온다.
- 하단 여백에 슬라이드 번호(`3/6`)를 넣어 완주 심리를 만든다.
- 각 슬라이드는 **캡션 없이도 이해**되어야 한다.
- **오리지널리티**: 2026년 4월부터 캐러셀에도 리포스트 판정이 적용된다.
- 나무의 잎·가지는 올리보다 반 박자 늦게 반응한다. 컷 사이에서도 유지한다.

## Phase 1 캐러셀 소재

- 올리의 하루 (아침 → 밤, 날씨가 계속 바뀜)
- 올리가 우는 날 vs 나무가 좋아하는 날 (4컷)
- 올리의 소지품 도감 (둥근 돌, 작은 쪽지, 접힌 지도)
- 구름 부푸는 정도별 기분 (씨앗 → 날씨 → 나무 3단계 시각화)
- 나무가 보내는 신호 6가지
- 올리가 화내는 법 (아주 작은 번개 시리즈)
- 열매가 맺히는 날 (미스터리 힌트 포함, C3)

**만들지 않는 것**: 목표 설정법, 공부 계획, 습관 만들기, 앱 기능 소개. Phase 4 이후 소재다.
