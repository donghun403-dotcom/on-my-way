# 마케팅 검수

On My Way 콘텐츠를 게시 전 6개 축으로 검수한다. **문제만 지적하지 말고 반드시 대체 문구를 함께 제시한다.**

> **Phase 1(캐릭터 각인) 안내**: 지금은 앱·기능·가격을 노출하지 않으므로 축 1~4는 대부분 해당 사항이 없다. Phase 1 콘텐츠의 주 검수 도구는 `on-my-way-brand`의 `references/ollie-voice.md` **§11 캐릭터 일관성 체크리스트**와 아래 **축 7(정신건강·캐릭터 묘사)**이다. 이 스킬을 Phase 1에서 호출하면 축 5·7만 적용하고 나머지는 "해당 없음"으로 처리한다.

## 검수 절차

1. 검수 대상 텍스트를 전부 수집한다 — 캡션, 릴스 자막, 캐러셀 슬라이드 텍스트, 화면 내 텍스트, 랜딩 문구까지. Meta는 **광고 문구·이미지·랜딩페이지·댓글을 통합 평가**하므로 캡션만 보는 검수는 무의미하다.
2. 아래 축을 순서대로 적용한다. Phase 1이면 축 5·7만, Phase 4 이후면 전부 적용한다.
3. 결과를 표로 출력한다: `위험도 | 원문 | 위반 사유 | 대체 문구`
4. 위험도는 **차단 / 주의 / 통과** 3단계.

## 축 1. Meta 개인 속성 정책

2026년 심사는 **암시된 개인 속성에도 공격적으로 플래그**한다. 간접 표현도 걸린다.

**금지**: 시청자를 직접 지칭하면서 성향·상태·부족함을 규정하는 표현.

| ❌ 차단 | ⭕ 대체 |
| --- | --- |
| "당신은 INFP라 계획을 못 지키죠" | "성향에 따라 실행 계획을 다르게 설계합니다" |
| "의지박약인 당신을 위한 앱" | "계획이 자꾸 틀어질 때 다시 짜주는 앱" |
| "작심삼일만 반복하는 당신" | "작심삼일을 전제로 설계한 계획" |
| "혼자 외롭게 공부하는 당신에게" | "혼자 하는 공부에 체크인 파트너를 붙였습니다" |
| "살 안 빠져서 고민이라면" | "6개월 감량 목표를 하루 단위로 쪼갭니다" |

**통과 원칙**: ① 제품·과정·일반적 혜택 중심 ② 3인칭 ③ 사용자가 스스로 고르는 자기식별형("내 MBTI 유형 보기")

**추가 주의 카테고리**: 정신건강, 체중감량, 부채·빈곤, 외로움. On My Way는 다이어트·자기계발 소재를 다루므로 이 축에 자주 걸린다.

## 축 2. 운세·사주 표현 (표시광고법 과장광고)

사주·운세 전용 규제는 확인되지 않았으나, **거짓·과장 광고 금지 조항이 그대로 적용**된다. 타깃이 시험·취업 준비층이라 "절박함을 이용한 표현"으로 해석될 여지가 크다.

| ❌ 차단 | ⭕ 대체 |
| --- | --- |
| "사주로 당신의 합격을 예측" | "명리학 기반 성향 분석으로 공부 방식을 제안" |
| "운세대로 하면 반드시 성공" | "성향에 맞는 방식이면 지속 확률이 올라갑니다" |
| "올해 대운이라 지금이 기회" | "지금 시작하면 목표일까지 며칠 남았는지 계산해드립니다" |
| "이 유형은 무조건 붙어요" | "이 유형에 맞는 루틴은 이렇게 짭니다" |
| "3개월 안에 900점, 하루 47분입니다" | "3개월이 하루 47분이 되는 계산" |

**판정 기준 하나 더**: **목표 수치 + 기간 + 실행량을 한 문장에 묶으면** 성과 달성 단정으로 읽힌다. 계산·설계 프레임으로 바꾸고, 계산의 전제(총량 가정치 등)를 콘텐츠 안에 명시한다.

**규칙**
- 효과 **보장·예측 단정형** 서술 금지
- 사주는 "운명 결정"이 아니라 **"목표 설정 스타일을 찾기 위한 참고 데이터"**로만 설명한다 (제품 스펙에도 명시된 원칙)
- 운세 소재 콘텐츠에는 **"참고·오락 목적"** 취지를 한 줄 넣는다
- 종교적·영적 프레이밍은 피한다 (Meta 개인 속성에 "종교" 포함)

## 축 3. 구독 고지 (전자상거래법 다크패턴)

2026년 6월 정부 발표로 **과태료가 500만원 → 1,000만원으로 2배** 인상되었고, 2027년 1분기부터 서비스 변경 시 사전 고지·동의가 의무화된다. 규제 초점은 "가입은 쉽고 해지는 어려운" 구조다.

**체크리스트**

- [ ] "무료 체험"을 소구하면 **자동결제 전환 조건을 같은 화면에** 병기했는가
- [ ] 병기 위치가 캡션 **첫 줄** 또는 영상 **자막**인가 (더보기 뒤·해시태그 더미 속 금지)
- [ ] 해지가 가입과 같은 난이도로 가능하다는 사실이 사실인가
- [ ] "무료"만 크게, 조건은 작게 쓰지 않았는가

**표준 병기 문구** (결제 활성화 이후에 사용):
> 1일 무료 체험 · 이후 월 2,900원 · 언제든 해지 가능

**현재 유의**: On My Way는 결제가 아직 비활성(`PAYMENTS_ENABLED=false`)이다. 결제 활성화 여부를 확인하지 않은 상태에서 "지금 구독하세요" 계열 CTA를 승인하지 않는다.

## 축 4. 협찬·광고 표기 (공정위 추천·보증 심사지침)

현금뿐 아니라 **무료 제품, 할인, 수수료 등 어떤 경제적 이해관계라도** 있으면 표시 의무가 발생한다.

**4원칙**: 명확성 · 접근성 · 인식 가능성 · 한국어

**인스타그램 정답**: 브랜디드 콘텐츠 라벨 활성화 **+ 본문 첫 줄에 "#광고" 또는 "협찬"** 병기

| ❌ 금지 | 이유 |
| --- | --- |
| `#ad`, `#sp` 단독 | 영문 축약어 — 한국 소비자 대상 부적합 |
| "더보기" 뒤에 배치 | 접근성 위반 |
| 해시태그 더미 속에 섞기 | 인식 가능성 위반 |
| 작은 글씨·낮은 대비·짧은 노출 | 인식 가능성 위반 |

위반 시 공정위 시정명령·과징금·공표명령.

## 축 5. 사실 검증 (내부 규칙)

법이 아니라 브랜드 신뢰 문제. 그래도 매번 본다.

- 사용자 수, 달성률, 후기, 수상 이력 등 **검증 안 된 수치가 들어갔는가** → 즉시 차단. `on-my-way-brand` 스킬의 팩트시트에 없는 숫자는 쓰지 않는다.
- **아직 없는 기능**을 현재형으로 말했는가 → 캘린더 연동, 친구·스터디 공유, 챌린지, 전문가 코칭, 팀 목표 관리는 후속 기능이다.
- **애플 로그인**을 언급했는가 → 미구현.
- 앱스토어·플레이스토어 링크를 전제했는가 → 스토어 등록 상태를 먼저 확인한다.

## 축 6. 비교·비방 광고 (표시광고법 제3조)

표시광고법은 **비방적인 표시·광고**를 부당광고로 규정한다. **실명을 쓰지 않아도** 특정 가능한 경쟁 제품군을 부정적으로 묘사하면 대상이 된다.

On My Way는 "연속 기록(스트릭) 압박이 없다"는 차별점을 갖고 있어 **타 습관앱을 깎아내리는 구도로 빠지기 쉽다.** 이 축은 매번 본다.

| ❌ 차단 | ⭕ 대체 |
| --- | --- |
| 타 앱 UI 패러디 + "여기서 협박이 시작되죠" | 유저 감정 재현 — "못 한 날엔 앱 열기가 싫어진다" |
| "보통 앱들은 연속 기록 끊겼다고 겁을 줍니다" | "On My Way는 실패한 날에 아무것도 빼앗지 않습니다" |
| "○○ 같은 앱 쓰다 지쳤다면" | "3개월짜리 목표라면 못 하는 날은 반드시 옵니다" |

**원칙**: 대비는 만들되 **우리 방식의 서술로만** 만든다. 타 서비스의 동작을 묘사하지 않는다. 경쟁 앱의 실명·로고·UI도 당연히 쓰지 않는다(상표 리스크는 별개 문제로 함께 확인한다).

## 축 7. 정신건강·캐릭터 묘사 (Phase 1의 주 검수 축)

올리 콘텐츠는 감정을 소재로 한다. 법 이전에 **사람이 다치지 않게** 만드는 문제다.

| ❌ 차단 | ⭕ 대체 |
| --- | --- |
| 우울을 "마음먹기 나름"으로 해결하는 전개 | 감정을 알아차리고 쉬면서 균형을 되찾는 전개 |
| 나무가 완전히 죽어 회복 불가로 끝남 | 시들어도 새순의 가능성을 한 컷 남김 |
| 올리가 찢어지거나 잔인하게 다치는 연출 | 구름 조각이 떨어졌다가 다시 붙는 정도 |
| 자해·극단적 선택을 연상시키는 장면 | 사용하지 않는다 |
| "별일 아니야", "금방 괜찮아질 거야" | "나도 이제 조금 쉬어야겠어요" |
| 감정을 훈계로 정리 ("긍정적으로 생각해") | 훈계하지 않고 상태만 말한다 |

**체크 항목**

- [ ] 정신건강 문제를 의지나 긍정으로 해결되는 것처럼 묘사하지 않았는가
- [ ] 나무가 시들어도 **회복 가능성**이 남아 있는가
- [ ] 감정을 억지로 없애거나 평가하지 않았는가
- [ ] 귀여움을 위해 올리나 나무를 잔인하게 다치게 하지 않았는가
- [ ] 밈을 썼다면 올리의 말투와 세계관이 훼손되지 않았는가
- [ ] `ollie-voice.md` §12의 미확정 설정(팔·다리, 성별, 색상값)에 의존하지 않는가

무거운 감정(깊은 슬픔, 외로움)을 다루는 편은 **여운을 남기되 방치하지 않는다.** 다음 에피소드까지 이어지는 상태는 허용하지만, 그 편 안에 최소한 나무의 작은 반응 하나는 남긴다.

## 출력 형식

```
## 검수 결과: [콘텐츠 제목]

전체 판정: 차단 2건 / 주의 1건 / 통과

| 위험도 | 원문 | 사유 | 대체 문구 |
| --- | --- | --- | --- |
| 차단 | ... | Meta 개인 속성 (시청자 직접 지칭) | ... |
| 주의 | ... | 구독 고지 위치 | ... |

### 수정본 전문
(대체 문구를 반영한 완성 캡션/대본 전체)
```

수정본 전문은 **항상** 붙인다. 지적만 하고 끝내지 않는다.

## 면책

법률 자문이 아니다. 인플루언서 협업 계약, 결제 활성화, 대규모 유료 광고 집행 전에는 광고법 전문 변호사 검토를 권한다. 구독 결제와 운세 표현이 결합된 구조라 실제 검토 필요성이 낮지 않다.
