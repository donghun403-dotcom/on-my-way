# SNS 성과 리뷰

숫자를 해석하는 게 아니라 **다음 주에 뭘 바꿀지**를 정하는 스킬이다. 분석만 하고 끝내지 않는다.

## 1. 받을 데이터

사용자에게 아래를 요청한다. 전부 없어도 진행한다 — 있는 것만으로 분석하고 무엇이 없어 결론이 약한지 명시한다.

**게시물별** (인스타 인사이트 → 게시물 → 조회수 탭)
- 조회수(Views), 도달, 좋아요, 댓글, **저장**, **공유(Sends)**, 프로필 방문
- 릴스는 추가로: **평균 시청 시간**, 영상 길이

**계정 단위** (인사이트 → 총 조회수 / 팔로워)
- 주간 총 도달, 팔로워 순증, 프로필 방문, **외부 링크 클릭**

**전환** (Phase 4 이후에만)
- 가입 수, 무료 체험 시작 수

**Phase 1에서는 전환 데이터를 요청하지 않는다.** 앱을 노출하지 않으므로 측정 대상이 아니다. 대신 댓글 내용을 텍스트로 받아 정성 평가(아래 §4)에 쓴다.

## 2. 계산할 지표

인스타가 직접 안 보여주므로 직접 계산한다.

| 지표 | 계산식 | 벤치마크 |
| --- | --- | --- |
| 인게이지먼트율 | (좋아요+댓글+저장+공유) ÷ 도달 | 인스타 평균 **0.48%** / 목표 1.0%+ |
| **완주율** | 평균 시청시간 ÷ 영상 길이 | 교육형 30초 기준 **50%+** |
| **저장율** | 저장 ÷ 도달 | 목표 2%+ |
| **Sends율** | 공유 ÷ 도달 | 목표 1%+ — 알고리즘 최상위 신호 |
| 프로필 전환율 | 프로필 방문 ÷ 도달 | 목표 3%+ |
| 링크 클릭률 | 링크 클릭 ÷ 프로필 방문 | 목표 5%+ |

## 3. 진단 로직

지표별로 **어디가 고장났는지**를 특정한다.

| 증상 | 원인 | 조치 |
| --- | --- | --- |
| 도달 낮음 + 완주율 낮음 | **훅 실패** | 첫 1초 재설계. 훅 A/B를 Trial Reels로 테스트 |
| 도달 낮음 + 완주율 높음 | 배포 부족 | Sends 유도 CTA 강화, 게시 시간 변경 |
| 완주율 높음 + 저장 낮음 | 재사용 가치 없음 | 요약 슬라이드/체크리스트형으로 전환 |
| 저장 높음 + 프로필 방문 낮음 | 브랜드 각인 실패 | 마지막 2초 제품 연결 강화, 프로필 소개문 점검 |
| 프로필 방문 높음 + 링크 클릭 낮음 | **바이오 문제** | 바이오 첫 줄과 링크 라벨을 구체화 |
| 댓글 없음 | CTA 부재 | 캡션에 질문 1개 + 댓글 키워드 CTA 1줄 (댓글 +202.8%) |
| 전체 하락 | 오리지널리티 판정 가능성 | 리포스트·워터마크 여부 점검 |

## 4. 축별 성과 판정

축마다 **주력 지표가 다르다.** 같은 잣대로 비교하지 않는다.

### Phase 1 (캐릭터 각인) — 현재

| 축 | 성공 판정 지표 | 실패해도 되는 지표 |
| --- | --- | --- |
| C1 감정 날씨 | 공유(Sends), 완주율 | 저장 |
| C2 올리 ↔ 나무 | 저장, 공유 | 프로필 방문 |
| C3 여정의 단서 | **댓글의 내용**(추측·질문이 나오는가), 팔로우 | 도달, 저장 |
| C4 참여 | 댓글 수, 스토리 응답 수 | 도달 |

**Phase 1의 최우선 지표는 팔로워 순증과 Sends율이다.** 링크 클릭·가입은 이 단계에서 측정 대상이 아니다. 앱을 노출하지 않으므로 0이 정상이다.

**Phase 1 고유 지표 — 정성 평가.** 숫자보다 이쪽이 중요할 수 있다. 매주 확인한다.

- 댓글에서 **올리를 이름으로 부르는가** ("올리 귀엽다" vs "이 캐릭터 뭐예요")
- **나무에 대한 언급**이 나오는가 (나무를 동반자로 인식했다는 신호)
- **미스터리 추측 댓글**이 자발적으로 나오는가 (C3 성공의 유일한 판정 기준)
- 팬아트·따라 그리기·자기 감정 공유 같은 **UGC**가 발생하는가

이 4가지 중 2개 이상이 반복 관찰되면 **Phase 2 전환 조건**에 도달한 것이다.

### Phase 4 이후 (앱 공개)

| 축 | 성공 판정 지표 | 실패해도 되는 지표 |
| --- | --- | --- |
| 캐릭터 | 공유, 팔로우, 댓글의 정성 | 링크 클릭 |
| 정보 | 저장 | 공유 |
| 제품·전환 | 프로필 방문, 링크 클릭, 가입 | 도달, 좋아요 |

**흔한 오판**: 전환 축 게시물의 도달이 낮다고 실패로 보는 것. 전환 축은 도달이 아니라 전환으로 평가한다. 반대로 캐릭터 축이 링크 클릭 0이라고 실패가 아니다.

## 5. 표본 경고

- 게시물 3개 이하로 결론 내지 않는다. **최소 4주 12개**가 쌓여야 축별 비교가 유효하다.
- 한 게시물이 크게 터진 주는 평균이 왜곡된다. 중앙값도 함께 본다.
- 게시 시간 변경, 축 배분 변경, 훅 스타일 변경을 **동시에 하지 않는다.** 한 번에 하나만 바꾼다.

## 6. 출력 형식

```
# 성과 리뷰 — MM.DD ~ MM.DD

## 한 줄 결론
(이번 주 가장 중요한 발견 하나)

## 지표
| 게시물 | 축 | 포맷 | 도달 | ER | 완주율 | 저장율 | Sends율 | 판정 |

계정 단위: 도달 N / 팔로워 +N / 링크 클릭 N

## 벤치마크 대비
- 인게이지먼트율 X% (평균 0.48%, 목표 1.0%) → 상회/미달
- ...

## 진단
1. (증상 → 원인 → 근거)

## 다음 주 조치 (최대 3개)
1. [바꿀 것] — [이유] — [측정 방법]

## 이번에 판단 못 한 것
- (데이터 부족으로 결론 못 낸 항목)
```

**다음 주 조치는 최대 3개.** 그 이상은 실행되지 않고, 무엇이 효과였는지도 구분할 수 없다.

## 7. 리뷰 이후

조치 사항을 `content-calendar`에 반영해 다음 캘린더를 갱신한다. 축 배분·게시 시간·훅 스타일 중 **이번에 바꾸기로 한 하나**만 반영한다.
