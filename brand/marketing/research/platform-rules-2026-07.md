# 플랫폼 규칙·사양·벤치마크 (2026년 7월 기준)

출처는 문서 하단. 수치가 바뀌었을 가능성이 있으면 사용자에게 알리고 최신 확인을 제안한다.

## 1. 포맷별 효율 — 무엇을 만들어야 하는가

Metricool 2026 스터디(게시물 2,430만 건 / 계정 37.5만 개) 및 Socialinsider 2026 벤치마크 기준.

| 지표 | 수치 |
| --- | --- |
| 릴스 인터랙션 | 단일 이미지 대비 **4배** |
| 캐러셀 저장 | 단일 이미지 대비 **9배** |
| 단일 이미지 인게이지먼트 | 전년 대비 **-45.98%** |
| 단일 이미지 도달 | 전년 대비 **-21.96%** |
| 인스타 전체 평균 ER | **0.48%** (캐러셀 0.55% / 릴스 0.52% / 이미지 0.37%) |
| 릴스 평균 시청시간 | **8.5초** |
| 질문 포함 게시물 | 댓글 **+36.70%** |
| 댓글 유도 CTA 포함 | 댓글 **+202.78%** |

| 해시태그 사용 게시물 | 조회수 **-31.70%**, 인터랙션 **-33.89%** |

**결론**: 릴스 = 도달, 캐러셀 = 저장, 단일 이미지 = 사실상 폐기.

## 2. 알고리즘 신호 우선순위

1. **DM 공유(Sends)** — 릴스 배포에서 가장 무겁게 가중되는 신호. "친구에게 보내기"를 유도하는 콘텐츠가 최우선.
2. **저장(Saves)** — 캐러셀의 주 무기.
3. **댓글** — 브랜드가 CTA로 직접 유도할 수 있는 유일한 신호. 댓글 유도 한 줄로 +202.78%.
4. **시청시간/완주율** — 3초 지점 이후의 시청시간이 리텐션 신호.

### 2026년 4월 오리지널 콘텐츠 정책
- 주로 타인 콘텐츠를 리포스트하는 계정은 피드·Discover **추천에서 제외**.
- "오리지널" = 완전 창작 또는 실질적 변형. 밈 + 코멘터리는 인정.
- **워터마크 추가나 속도 변경만으로는 오리지널로 인정 안 됨.**
- 릴스뿐 아니라 **정지 이미지·캐러셀에도 확대 적용**.
- 팔로워 노출에는 영향 없고 추천 도달에만 영향.

### 해시태그
- 2024년 12월 해시태그 팔로우 기능 제거. 도달 기여 사실상 없음.
- **3~5개로 제한.** 도배 금지.
- 대신 **캡션·프로필·대체텍스트의 자연어 키워드**가 검색 노출에 기여.
- On My Way 캡션 키워드 풀: 목표달성, 습관만들기, 공부계획, 시험공부, 루틴, 자기계발, MBTI, 사주, 취준, 다이어트

## 3. 릴스 사양

| 항목 | 값 |
| --- | --- |
| 해상도/비율 | 1080 × 1920px, 9:16 |
| 커버 | 1080 × 1920px 업로드, **핵심 요소는 중앙 1080×1080 안에** |
| 프로필 그리드 표시 | 3:4 (1080 × 1440px) |
| 세이프존 (텍스트 금지) | 상단 220px · 하단 450px · 좌우 각 35px |
| 포맷/코덱 | MP4 / H.264 (H.265 피할 것) |
| 프레임레이트 | 30 FPS |
| 비트레이트 | 3,500~5,000 kbps |
| 길이 (플랫폼 한계) | 최소 3초, **3분 이내 기획 권장** |
| 자막 | 필수 (완주 가능성 +80%) |

**인코딩 주의**: 인스타가 재인코딩하므로 최고 품질 원본에서 **1회만** 내보낸다. 다중 압축 금지.

**운영 기준 길이**: 위 표는 플랫폼 한계다. On My Way의 실제 제작 길이는 `reels-script` 스킬 기준(**20~40초**, 정보량이 많으면 최대 60초)을 따른다.

### 완주율 목표 (교육·정보형 기준)

| 길이 | 목표 |
| --- | --- |
| 15초 미만 | 65%+ |
| 15~30초 | 50%+ |
| 30~60초 | 40~50% |
| 60~90초 | 35%+ |

리텐션 %는 인스타가 직접 안 보여준다. **평균 시청시간 ÷ 영상 길이**로 직접 계산한다.

> 완주율 80%의 15초 릴스가 완주율 20%의 3분 릴스를 이긴다.

## 4. 캐러셀 사양

| 항목 | 값 |
| --- | --- |
| 비율 | 1080 × 1350px (4:5 세로) — 1:1 대비 피드 점유 면적 +33% |
| 장수 | **5~8장 권장** (최대 20장). 4장 미만은 저장 유인 약함, 10장 초과는 완주율 하락 |
| 1번 슬라이드 | 제목이 아니라 **훅** |
| 마지막 슬라이드 | 그것만 저장해도 가치가 완결되는 **요약 슬라이드** |

3번째 슬라이드 이상 스와이프되면 알고리즘이 재배포하는 경향이 있어, 게시 24~48시간 후 2차 노출이 오는 경우가 있다.

## 6. 링크·전환 구조

| 위치 | 현황 |
| --- | --- |
| 프로필 바이오 링크 | 최대 **5개** |
| 스토리 링크 스티커 | **전 계정 사용 가능** (팔로워 요건 폐지됨) |
| 피드 캡션 링크 | **클릭 불가** (Meta Verified만 최대 10개 삽입 가능) |
| 댓글 키워드 → DM 자동화 | 가능 (아래 제한 준수) |

**바이오 링크 5슬롯 권장 배치**: ① 앱 시작하기 ② 성향 목표 진단 ③ 요금제 ④ 후기·사례 ⑤ 문의

**CTA 원칙**: 구체성이 클릭을 만든다.
- ❌ "프로필 링크 확인"
- ⭕ "댓글에 '올리' 남기면 MBTI별 목표 계획표 DM으로 보내드려요"

### DM 자동화 제한 (위반 시 계정 정지)
- **24시간 창**: 사용자의 마지막 상호작용으로부터 24시간 내에만 자동 DM 발송 가능
- **선행 인게이지먼트 필수** — 콜드 아웃리치 금지
- **시간당 200건 한도** (안전선 150건), 사용자당 트리거 DM은 24시간당 1건
- **공식 Meta Graph API 기반 도구만 사용.** 브라우저 자동화·크롬 확장·비밀번호 요구 도구는 즉시 제재 위험
- 자동화 플로우 안에 사람 연결 옵션 유지

### 앱 설치
- 앱 다운로드의 **65%가 스토어 검색에서 발생** → SNS 단독으로는 한계, ASO 병행 필수
- 스토어 설명문은 **첫 3줄**이 결정적
- 평점 4.0 미만이면 전환율 급락
- 리뷰 요청 최적 타이밍: 앱 실행 직후가 아니라 **핵심 성공 경험 직후** → On My Way라면 "7일 연속 체크인" 또는 "올리 성장 단계 진입" 시점
